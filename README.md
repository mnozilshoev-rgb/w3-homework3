# Hotel Booking Website

A modern and responsive hotel booking website built using HTML and Tailwind CSS. This project features a clean UI design for hotel discovery, booking, facilities overview, and customer engagement.

## Preview
This website includes:
- Responsive Navbar
- Hero Section
- Hotel Listings
- Facilities Section
- About / History Section
- Testimonials
- Map Section
- Footer

---

# Features

## 1. Navigation Bar
- Clean and minimal navbar
- Quick access to:
 - Booking
  - Facilities
  - About Us
  - Location
  - Contact

## 2. Hero Section
- Attractive landing page
- Large background image
- Search functionality
- Booking form with:
  - Location
  - Check-in date
  - Check-out date
  - Number of rooms

## 3. Popular Hotels
Displays hotel cards with:
- Hotel image
- Hotel name
- Price per night
- Rating

## 4. Facilities
Provides available services:
- Private Workspace
- Parking Area
- Breakfast
- Free WiFi
- Free Electricity
- Swimming Pool
- Exercise Space
- Other Services

## 5. About Section
- Introduces hotel history
- Brief company description
- CTA button

## 6. Testimonials
- Customer reviews
- User feedback section

## 7. Location Section
- Hotel location displayed on map
- Contact input form

## 8. Footer
Contains:
- Navigation links
- Help section
- App download links

# Installation

1. Clone repository:
```bash
git clone <repository-link>
```

2. Open project folder:
```bash
cd hotel-booking-website
```

3. Install dependencies:
```bash
npm install
```

4. Run Tailwind:
```bash
npm run dev
```
